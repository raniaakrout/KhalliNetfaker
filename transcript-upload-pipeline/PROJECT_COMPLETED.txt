📞 SUPPORT GUIDE
================================================================================

PROBLEM                          SOLUTION
─────────────────────────────────────────────────────────────────────────────
Can't connect to backend         → Check .env.local, backend running?
Build errors                     → Delete .next, reinstall, rebuild
API returning 401                → Login again, token expired
File upload fails                → Use .txt files only
UI looks broken                  → Clear browser cache (Ctrl+Shift+Del)
Slow performance                 → Check backend logs, database queries
Port already in use              → Kill process or use PORT=3001 pnpm dev
